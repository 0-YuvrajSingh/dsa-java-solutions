## Pattern Recognition

**17 problem-solving patterns** mapped across all problems:

| Pattern | When to Use |
|---------|-------------|
| Sliding Window | Subarray/substring with contiguous elements |
| Two Pointers | Sorted arrays, pair/triplet problems |
| Fast & Slow Pointers | Cycle detection, middle of linked list |
| Monotonic Stack | Next Greater/Smaller Element |
| Prefix Sum | Range sum queries, subarray sum |
| BFS / DFS | Graph/Tree traversal, level-order |
| Backtracking | Permutations, combinations, constraint-based |
| DP - Knapsack | Subset sum, partition, coin change |
| DP - LIS | Longest Increasing Subsequence |
| DP - LCS | Longest Common Subsequence, Edit Distance |
| DP - Grids | Matrix traversal, unique paths |
| Merge Intervals | Overlapping intervals |
| Cyclic Sort | Missing/duplicate in [1, n] |
| Top K Elements | Kth largest/smallest |
| Union-Find | Connected components |
| Bit Manipulation | XOR tricks, subsets, power of two |
| Greedy | Activity selection, optimization |

See `src/patterns/` for detailed pattern descriptions with templates.
