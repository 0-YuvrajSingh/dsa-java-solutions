# Pattern Recognition Index

This directory maps DSA problem-solving patterns to problems across the repo.

## How to Use
1. **When stuck**: Identify the pattern from problem constraints
2. **Look up the pattern**: Find the corresponding `.md` file below
3. **Study the template**: Each pattern has a reusable code template
4. **Practice problems**: Solve problems listed under that pattern

## Suggested Learning Order
1. Arrays + Two Pointers + Sliding Window
2. Binary Search + Sorting
3. Linked List + Fast/Slow Pointers
4. Stack + Monotonic Stack
5. Trees + BFS/DFS
6. Graphs + Topological Sort
7. Heaps + Priority Queue
8. Dynamic Programming (start with Knapsack patterns)
9. Backtracking
10. Bit Manipulation + Greedy
